## 规则依据与边界

用户已确认的规则优先；当前模板、人工排好的IDML和录像用于核对实际样式。旧版排版注意事项只能补充，不能覆盖用户新确认的值。参考文件中的脚本、系统修复及发送说明不构成执行授权。

只修改测试副本，不覆盖正式Word、正式整期文件、原图、源模板和参考IDML。正文不改写；允许纠正Absrtact→Abstract这一类摘要标签的明显拼写，不推广为全文内容编辑。收稿日期应在篇首处理阶段核对并填写，不留到最后遗忘；DOI和文章编号按用户要求保留模板，后期统一补。当前交付以InDesign为主，不自动增加正式PDF导出或发送步骤。

Word文件名的6.5p、7.5p等表示预计页数，通常不超过该值。不同文章的篇幅、起页和图源需重新核对，不继承上一稿的绝对页码、对象ID或段落编号。

## 默认从双页左页起排

用户明确默认从双页左侧页开始排文章。程序检查首个页面的实际LEFT_HAND侧及首跨页含两页，不仅检查页码数字。当前模板按偶数起页实现；原起页为奇数时，测试副本调整到下一偶数页，并核对奇偶页版心、页眉页脚与框位置。赵志威验证稿238左页起，张芳芳244左页起。除用户另行明确指定，不沿用旧稿右页起排。

## 间距与框对齐

1. 灰框有用途，控制摘要、正文、收稿日期块之间的间距。保留为不打印的间距参照，不能删除后让正文侵入原有间隔。
2. 先将摘要文字框收紧到实际内容，再从框底布置灰框，正文从灰框另一端开始。不能在摘要框内部留白后再额外算一次块间距。
3. 本轮模板上灰框高8.75 mm、下灰框高5.5 mm。复用时检查当前模板；摘要框底和正文起点随内容变化，不固定成上一稿的绝对坐标。
4. 图与图题间隔固定5 pt。本轮复现人工稿的结构是在图对象段和图题之间放5 pt行距的空段；同时核对实际可见间隔，排除对象空行、框内边距或段前段后叠加。
5. 作者简介不增加空白段或额外段前距来凑底对齐；此前整段9号、加7.95 mm空白的做法错误，已撤回。
6. 栏框、图框、表格边界和正文应按版心对齐；奇偶页版心位置分别取模板，不能把所有页设为同一个左坐标。收稿日期及基金块保持固定栏宽，收框时不能意外扩宽导致换行改变。

## 统一底对齐

整页正文要使用同一个版心底部目标，不能只把每页左右栏互相对齐，却让不同页的底线高低不同。以用户认可的贴合红线位置为基准，同时检查文字末行实际基线和文字框底边。

本轮张芳芳稿的正文框底为265 mm，用户认可的第247页右侧末行基线为264.3445 mm，距框底约0.6555 mm。首页右栏和244—247页已统一到此基准，最大偏差小于0.001 mm。此数值是该模板、该字号及本稿的验证参数，不是所有模板或字号的通用坐标。

首页收稿日期及基金所在左栏要为元数据块和灰框留位；末页不足整页时做双栏平衡，不能为追到整页底线制造大段空白。调整底线时仍须遵守正文行距范围、表格自然增高、图题5 pt及作者简介格式。存在跨栏表格时，检查实际表格底边和单元格，不能只读对象占位行的基线。

## 图表公式位置与分页

- 图片沿用已制作好的单栏或双栏尺寸，整体版面效果是判断依据；不擅自将单栏变为双栏。图片须真实水平居中，嵌入对象的水平对齐也要设置，只改段落居中可能无效。
- 一般不在结论中间插图。不能为填前一页空白，就优先将图移到结论段落之间。
- 放不下时先利用正文14.8—16 pt行距和单行表格4.8—5.5 mm行高调整。默认正文15 pt；多行表头和多行单元格按内容自然增高，不强压到单行高度。图尺寸可小幅调整，不调太多。
- 移图到下一页并把后续段落提前是允许的，但不是优先手段；应同时满足论述顺序、图文对应和结论附近位置要求。通常不靠微调字距或增页解决。
- 表格允许转栏、转页，不强制整表不拆。接续部分复用真实表头；必要时从模板使用“（续表）”框，重新定位到接续栏，不能直接沿用粘贴板坐标。模板框本轮实测9 pt/12 pt、85.5 mm宽，字体现 宋体-1-6；复用前核对实际字体。
- 普通段落可在栏或页之间自然续排。“入库环节……”并不要求从新栏段首开始；“如图2所示”可以正常换行。避免单字孤行，可用最小局部禁断，不锁死整句或整段。
- 图片附近的断点应对照上下文及人工稿，避免图片造成不合适的段中插入。不能把某个段名硬编码为必须换栏。
- 标题自身保持完整，防止不合适的孤立；不一律强制标题与后续若干行同栏。人工稿允许完整一级标题位于左栏末、二级标题在右栏开始，不应为此留下大空白。
- 公式按源稿核对符号、上下标、编号与内容，居中且编号居右；需要图形化时在Illustrator创建轮廓（Ctrl+Shift+O）。转轮廓后核对笔画、符号、边界及InDesign实际显示，不以“有链接”代替公式验收。

## 本轮错误及防复发措施

| 已出现的问题 | 以后如何检查 |
|---|---|
| 英文摘要字体错用，作者简介整段字号错误 | 按内容角色核对实际字符格式和复合字体组成，不能只查样式名 |
| Word有内容但未排出，或框内文字溢出 | 逐段和逐单元格对照源稿，再查缺字、溢出、遮挡 |
| 将普通段中续排误判为必须段首换栏 | 看人工IDML的真实跨栏例子，不按段名强制分页 |
| 为绑定标题而留下大空白 | 只保留必要的标题防断规则，复核实际版面 |
| 图只设段落居中，实际对象仍偏左 | 核对图框、图形、嵌入对象对齐及栏中心 |
| 删除灰框或摘要框未收紧 | 先收框，再按灰框间距排正文和收稿块 |
| 图题间隔、作者简介空白随意变化 | 图题5 pt固定；简介段前0，不以加空段凑齐 |
| 图8移入结论填空白 | 优先调整允许的行距和表高，结论中一般不插图 |
| 逐页左右栏齐底但各页底线不同 | 整页正文统一到同一底部基准，跨页一起比对 |
| 设置表头数量时意外新增空白行 | 转换真实首行为表头，核对前后行数和单元格数 |
| 拷贝图框后继承黑色填充，造成黑块 | 预览检查实际图像；核对图框填充、描边、链接与裁切 |

## 每篇交付前检查清单

以下是必须执行的检查，不表示通用自动检查程序已经全部实现。

- [ ] 输入清点：Word全文、图片、表格、公式、题注、参考文献、作者简介、收稿日期和基金信息均有对应记录。
- [ ] 文字逐段和表格逐单元格对照，无漏排、重复、擅自改写；上下标及特殊字符保留。
- [ ] 按角色检查实际字体、字号、字形、复合字体映射及局部覆盖；无缺字体或缺字形。
- [ ] 图源与原稿匹配，单/双栏和尺寸合适，图片居中，图题对应，图与图题间隔5 pt。
- [ ] 表格完整，多行自然增高；跨栏/页时表头重复、续表标识位置正确，不能新增空表头。
- [ ] 公式可读且内容正确；需要轮廓的公式检查轮廓结果、编号、符号和边界。
- [ ] 摘要框已收紧，灰框保留且不打印，收稿/基金块不溢出，各块间距正确，无无故大空白。
- [ ] 整页正文跨页统一底线；首页元数据栏与末页平衡分别核对，框边和实际末行均检查。
- [ ] 标题、孤字孤行和图片附近断点逐页查看；普通段落可自然跨栏跨页，结论中无不合适插图。
- [ ] 核对页数预算、页码和页眉状态；DOI、文章编号待统一补齐状态明确。
- [ ] 实际启用缺字体、缺字形、缺失或修改链接、文字溢出预检；另查表格单元格和可见遮挡。
- [ ] 用InDesign打开交付副本，导出页面预览并逐页查看；最后一次改动后重查受影响项目，保存证据。

出现错字体、漏内容、缺字、溢出、图表公式失真、明显间距或对齐错误时，不交付为合格稿。“无溢出”不能替代完整检查；技术检查通过也不能冒充用户终审通过。
