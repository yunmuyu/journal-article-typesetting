# 现成组件核查与局部复用

日期：2026-10-20。范围：在侧对话中评估可复用源码，做最小本地接入。
本次不接管主线程排版，不操作 Adobe 文档，不更改主线程检查点或生产文件。

## 结果

已复用 IdExtenso 的 UTF-16 码点解码算法，接入共享
`JournalLayout.orphanLine`。这是对单字孤行漏检的改进，不是底齐、
分页或完整自动排版引擎的替换，也未测得整篇排版提速。

原检查只识别 U+4E00—U+9FFF，扩展汉字及兼容汉字会漏检；
变体选择符也可能被误计为独立字符。补丁保留上标引用排除规则，
增加代理对解码与汉字区间判断。没有改写 `String.prototype`，
没有引入 IdExtenso 的全局环境和运行时依赖。

来源、许可、上游函数快照见
[third_party/idextenso/README.md](../third_party/idextenso/README.md)。

## 候选逐项结论

| 候选 | 核查所得 | 相对现有实现的决定 |
|---|---|---|
| IdExtenso `String.prototype.codePointAt` | MIT；可独立提取的代理对解码算法 | 已局部改编接入；已重现并修复9个边界测试的失败 |
| IdExtenso `$$.JSON` | 源码明确说明不严格符合 JSON，可输出 NaN、Infinity、undefined、构造器调用等脚本表达式 | 不采用。当前状态/测量结果由 `JSON.parse`、`ConvertFrom-Json` 读取，协议不兼容 |
| IdExtenso `TextParcels` | 可见文本、单元格、脚注的定位与索引；依赖 Dom、MultiStream、Linguist 资源及框架环境 | 保留为测量层参考。它不直接提供行高/底齐求解，本次没有速度或真实文档准确性证据，不能替换当前测量模块 |
| Peter Kahrel `missing_glyphs.jsx` | 官方下载本机访问失败；下载到固定 GitHub 镜像版本。使用逐字体 `findGlyph(glyphID=0)`，绑定活动文档、使用对话框、改变全局查找设置 | 不直接接入。现有规则已有原生 `ADBE_MissingGlyph` 预检；该脚本可以参考定位方法，但不是现成无交互批处理替代品 |
| Kahrel 镜像许可 | 仓库总许可 MIT，但第三方条款称 Kahrel 脚本保留 GPL-2.0；下载的单脚本头只有作者署名 | 不把仓库 MIT 误当第三方脚本授权。原作者版本与具体许可未核实，不复制进共享代码 |
| Typefi | 官方浮动对象变体、锚点、优先级和边界规则可作为分页设计参考 | 属于商业产品，本次没有取得可复用源码，不把产品文档当已经实现的能力 |
| Typefitter | 商业插件；脚本集成涉及额外选项；现行版本与 InDesign 2020 不匹配，历史版支持2020 | 未安装、未调用、未购买。尚无中文复合字体及本项目绝对行距/字距范围的实测，不能认定优于现有求解器 |
