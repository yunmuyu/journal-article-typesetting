# 正文缩进与图注间距检查契约

通用 `Check` 报告正文首行缩进与段落样式不一致。自动修复仅处理实际值为 0 的正文段，且审核配置须提供经模板核对的来源与精确样式：

```json
{
  "bodyIndentContract": {
    "styleName": "正文_wrd_1",
    "firstLineIndentPt": 22,
    "verified": true,
    "source": "已核对的本期模板正文段落样式"
  }
}
```

示例中的样式与 22 pt 仅说明字段格式；其他模板须逐一核对后填写，不从样式名称推断数值。未提供已核验契约、样式值与契约不符、或局部缩进为非零时，程序只报告差异，不自动覆盖。确有人工认可的局部缩进，可在仓库外的文章配置中增加精确例外：

```json
{
  "bodyIndentExceptions": [
    {"storyId": 123, "paragraphText": "完整段落文字", "reason": "人工确认的局部版式"}
  ]
}
```

例外同时核对故事 ID、完整段落文字和原因，不按页码或文章 ID 写入共享程序。

图与图注之间的空段行距固定 5 pt。`figureCaptionGapPt` 若提供也必须是 5；检查覆盖正文中锚定图片后的主图注和逐幅子图注，并报告局部段距叠加。行距属性和图框底到图注墨迹顶的可见距离是两项不同的测量：后者受锚定结构、字形影响，须以当前版面几何或预览复核。图像内部白边不计为段距。合成原生回归分别读取修复前后图框底及图注墨迹顶，验证 2→5 pt 时可见距离增加 3 pt。

续表同步依据表格当前实际跨框状态，仅处理已绑定故事中的表格与框。多栏文本框仍需人工审查；不得借用本检查将复杂续表自动化视为已完成。
