# v1.0.0 第一版基线

发布日期：2026-10-19。此独立项目版本固定本轮已验证的Word→InDesign导入、排版规范化与检查能力，后续文章在新提交中迭代，不移动此版本标签。

## 已固定能力

- Word正文与字符格式提取、InDesign导入、规定字体及英文摘要和作者简介格式。
- 共享规则模块与完整检查入口：灰框、图题5 pt、真实表头、图片居中、整页统一底线、末页齐底、默认双页左页起排。
- 对照本稿Word解析输入核对段落、表格单元格和上下标，检查复合字体映射、图源指纹与尺寸、结论插图、文字及单元格溢出。
- Apply前保存恢复副本，失败明确返回未通过；部署备份并核对脚本面板两个导入入口及共享模块的SHA256。

详细本地证据入口：本机Codex交付目录“2026-10-19/n/outputs/双篇程序验证/验证报告.md”。Git只保存结果摘要和程序指纹，不保存稿件原文、图件、INDD、IDML或页面预览；仓库中的sample_article.json为合成样例。

## 仍未完成

当前版本需要相应文章的装配稿、故事绑定和Word核对输入，不是任意Word直接全自动成稿。续表框自动定位、复杂公式通用自动转轮廓及全部审美判断尚未完成。遇到实际拆表，完整检查入口要求接续复核。字体和漏排等检查失败不能交付为合格稿。

## 后续版本原则

新增文章先做独立测试副本，修复和规则更改配对应回归；实稿资料保持本地。v1.0.0保留不动，向后修改通过新提交、新版本记录；不将一次文章的页码、story ID或绝对位置硬编码进共享模块。
程序指纹清单v1.0.0.sha256记录本机验证时的文件字节；Git可能按.gitattributes转换检出换行，跨机器应以版本标签及提交树确认版本，不直接把换行差异认作功能变化。

项目归属：独立私有仓库yunmuyu/journal-article-typesetting。原Word工具仅作组件来源；脚本使用独立子目录部署。旧仓库误发布已按用户要求另行撤回。
