# 组件来源与项目边界

本项目：期刊文章自动排版与检查系统，仓库yunmuyu/journal-article-typesetting。

依赖来源：yunmuyu/word-to-indesign-toolkit，原工具基线提交781bf6ca4f（完整提交可由旧仓库历史查询）。1-提取_Word转JSON中的提取器和拖拽入口以源码快照复用，保留相应提取回归。2-导入_InDesign的导入适配器以旧工具为基础，增加本系统规定字体、摘要标签和作者简介格式；该适配器属于本系统独立维护。

共享排版规则、完整检查入口、规则文档、两篇试排验证及第一版发布归本新项目。新项目使用独立Git历史，不把旧工具库的全部历史当成新项目历史。

2026-10-19曾误将新系统的两次提交和v1.0.0发布放入旧工具库。按用户要求纠正：在旧库以回退提交撤销误加功能，撤下误发Release及标签；保留旧库历史，不强推。新系统在独立目录、独立私有仓库固定v1.0.0。

本机部署使用脚本面板“期刊文章自动排版系统”子目录，与旧工具根目录入口分开。修复旧仓库归属不覆盖当前新系统的已验证程序及试排文件。
