# 2026-11-13 字符格式与交接修复候选

本轮仅进入开发候选，不合并正式版。真实稿件、字体、测量数据和本机配置不入库。

## 已验证

- 摘要恢复原文斜体及粗斜体，同时保留上下标、字号与行距；中文标点保持正体，拒绝失效字体引用。
- 正文源格式映射保留粗斜体，不再将粗斜体变量降为普通斜体。
- 简式转换完整运行源码收录于 `tools/simple-formula`。已有普通文本仅修复符合条件的字体槽位，不重判其数学语义，保留斜体、粗体、上下标和位置属性。
- 交接清理提供三项限定范围操作：删除造成空行的公式首制表符（失败回退）、文献类型标记恢复正体、删除已标记且不打印的间距辅助框。

回归通过：source_italic_idempotence、frontmatter_source_runs、handoff_cleanup、review_contract、existing_front_refit、frontmatter_module、简式字符格式测试、合成 DOCX 完整 CLI 转换。CLI 测试核对原稿哈希不变及输出字符属性。

本机实稿已在现有总稿中修正并检查导出 PDF：摘要变量、粗斜体变量、3处 ij 斜体下标、文献标记及辅助框。公式首制表符修复使相关段落由三行减至两行，未宣称编号与长公式同排一行。Σ 的原生字号与缩放核对为 10.5 pt、100%，本轮没有通过放大字形改变公式尺寸。

## 边界

- `JournalHandoffCleanup` 由调用方显式传入文章范围；尚未全局接入所有装配入口。
- 简式转换的旧 `.doc` 适配器随依赖闭包收录，本轮验证仅覆盖 DOCX。
- 本轮不宣称整期达到出版终检，也不改变离线求解器的可选定位；编辑保留的分页与作者简介独页未纳入自动修复。
- 实际版面证据留在私有交接记录，不随公共代码提交。
