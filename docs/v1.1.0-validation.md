# v1.1.0 — 整合验证版（源码，未部署）

PR #1 续表标记/回滚、正文缩进与图题间距；#2 测试桩及 WMF Python 启动；#3 表格来源/类型、原生格式与审核门禁；#4 间断页审核范围、原生末页、PDF解码门禁、复合字体数字与表序判断共同整合。有效的本地增量以净补丁引入，保留 Word 编号、页眉页脚、换栏所有权和底齐预算/回滚；没有引入含私有资料痕迹的旧本地历史。原分支保留。

验证：91组 JavaScript 回归、48项 Python 测试通过。Adobe 合成测试通过续表跨框/回缩、缩进/图题间距、自动换栏所有权/人工断点保护、底齐预算耗尽与回滚、表头/上标/右对齐/已批准行高保留。混合整数/小数列仍要求审核，不自动改写。图题5pt是属性契约，不把实际墨迹间距误称为5pt。

行高：普通表最低4.6mm；底齐优化只处理至少4.8mm的保守子集，不自动把已批准4.7mm行拉到4.8mm。原生合成测试确认4.7mm保留。复杂表格、通用空白求解、自动小数对齐及未经确认的大规模重排保留候选，不默认放行。

运行须另配合法字体、Adobe、来源绑定及私有文章配置。程序与合成原生验证不替代真实文章审校和 PDF 视觉验收；坏 PDF 必须被共用解码门禁拒绝。特定期次回放不证明通用接页完成。未部署到脚本面板或生产 runtime。

接页消费者原生复测发现：缺少 tableKinds 时复合属性访问在 ExtendScript 中抛 TypeError。补缺字段/空数组原生负例，修复前失败；改为分步存在性检查后返回 TABLE_KIND_REQUIRED，且不修改表格。原生用例和最终91组JS回归通过。配置缺失仍阻断，不能补造分类。
