# 自动换栏与栏尾空白执行约定

当前命令行入口为 `2-导入_InDesign/Invoke-JournalArticleReview.ps1`。顺序为正文规范化、BeforeBottom 空白试排、真实测量与底齐、AfterBottom 续表同步及空白复核、完整检查。空白阶段未通过不得导出验收预览或报告通过。尚未替换用户正在运行的脚本面板。

## 断点所有权

新自动断点必须通过 `JournalGapLayout.registerAutomaticBreak` 登记。释放成功会删除登记；之后人工重新加的换栏不能继承旧授权。未知或人工断点默认保留。迁移旧工具断点须在 `legacyAutomaticBreaks` 中提供准确 storyId、paragraphStart、text；`protectedColumnBreaks` 优先于自动授权。

压短后的末页框只能依据 `journal-auto-tail-capacity` 标签，或明确的旧断点配置 `tailCapacityMm` 恢复容量，不猜测所有框都应拉到页底。试排快照覆盖框坐标、段落断点、所有权和可调属性；失败恢复后保留问题。

## 范围与限制

合刊使用唯一 body binding 和 articlePageRange；范围不明确就拒绝执行。空白阶段可以在合刊副本中按文章运行；旧全篇 NormalizeExisting 尚未具备安全的合刊范围，因此 Review 对合刊原位规范化显式拒绝，不能绕过此限制。

默认试排最多4框、6候选、3边界、30秒，12毫米为大空白阈值。自动断点即使藏在已压短框中也应检查。大图尺寸或复杂跨栏结构超过试排能力时保留 blocked-large-gaps，不以扩大行距强行消除。

末页自然平衡调整成对正文框容量，不再生成永久 NEXT_COLUMN。完整一级标题可留在栏尾，二级标题可连随文从下一栏开始；显式 keepWithNext、二级标题和参考文献标题的跟随约束仍保留。候选估算必须再经真实组版检查，不能据估算直接通过。

## 页脚组件

Layout 正式检查默认加载 `journal_page_furniture.jsxinc`，逐页检查有效刊期组件存在、非隐藏/不打印、未溢出。检查范围遵循 articlePageRange。仅其他主页存在刊期不能满足本页。

`repairMissingDate` 只补确实缺失的组件，要求明确提供完整模板的同侧参考页；不替换整套主页，不改刊期内容。遮挡、颜色与页码本身仍需相应检查及预览，本组件不宣称覆盖所有视觉故障。
