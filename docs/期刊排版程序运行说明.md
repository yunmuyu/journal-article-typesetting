# 期刊排版规则程序运行说明

规则已经接入通用导入器和独立排版检查入口，不依赖赵志威、张芳芳的专用修订脚本。当前版本处理已装配文章的规范化与检查；图表装配、文章核对输入和故事绑定仍需按文章准备，不代表任意Word可直接全自动成稿。

## 入口

- import_word_article_to_indesign.jsx及0文章.jsx：导入正文、摘要角色和作者简介时设置规定格式，清理继承字符格式，保留源上下标/斜体。摘要标签Absrtact纠正为Abstract。规定字体不可用时中止，不悄悄退回其他正文字体。
- journal_layout_rules.jsxinc：共享规则，规范摘要与简介、灰框、图题间隔、真实表头、图片居中、默认左页起排及底线。规则检查与排版修复分开，程序不擅自移动结论中的图或改正文。
- journal_layout_and_check.jsx：InDesign脚本面板入口，选择文章JSON配置，处理测试副本并生成版面审计。它不做完整Word内容对照，弹窗已明确提示，不能只据此交付。
- Invoke-JournalLayout.ps1：完整入口，调用同一模块，再逐段/逐单元格/上下标与原稿解析输入对照，校验图源指纹与尺寸，发现错误抛异常、返回失败。

## 命令

从项目2-导入_InDesign目录运行：

```powershell
.\Invoke-JournalLayout.ps1 -ConfigPath "文章配置.json" -Mode Apply -ExportPreview
.\Invoke-JournalLayout.ps1 -ConfigPath "文章配置.json" -Mode Check
```

Apply先保存恢复副本，再规范版面、生成审计、保存QA候选稿、导出IDML及可选页面预览。候选稿保存不表示验收通过，以对应audit.result.json的passed和errors为准。Check用于检查已排文章。原生调用失败会明确记录passed:false，避免沿用旧成功状态。

运行前必须有文件名含QA、copy或副本的测试文件；程序拒绝普通生产文件名。正式文件、模板、Word与原图保持只读。修改脚本后运行deploy_to_indesign.ps1 -NoPause；部署到脚本面板“期刊文章自动排版系统”子目录，会备份该子目录旧文件，并核对导入器两个入口、共享模块和菜单入口的SHA256。

## 文章配置

两篇已验证配置位于本次交付的“配置”目录。字段说明：

| 字段 | 用途 |
|---|---|
| documentPath | 测试INDD路径 |
| bindings | 本稿各story的id及role：front、body、footer、doi、figures；首次注册后以journal-role标签查找 |
| sourceParagraphs | 从对应Word提取的全文段落及上下标核对输入，不是从InDesign反向生成的基准 |
| sourceTables | Word表格二维单元格数据，支持顶层tables或表格数组 |
| figureCount、graphicCount、tableCount | 应有图题、图形链接和表格数；公式图形计入graphicCount |
| pageBudget | Word文件名中的预计页数 |
| startOnLeft | 默认true；右页起排时改为下一偶数页并调整奇偶页版心 |
| assets | 已核对的图表公式文件名、尺寸、路径和SHA256；换图必须重新核验基准 |
| auditPath | 审计XML位置，同目录生成result.json、恢复副本和预览 |
| reviewedContinuedTables | 实际拆表后经人工看过重复表头及续表标识的表格序号；未核对时不设置 |

不要把旧文章的story ID、预计页数或图源指纹直接复制给新稿。核对输入须来自相应Word；换原稿时重新生成。当前字体、栏宽、灰框与底线参数对应已验证的本刊模板，其他模板须另做适配和验证。

## 阻断与仍需人工核对的部分

自动检查包含实际字体/字号/行距及复合字体映射、缺字/缺字体、全文段落与表格数据、上下标、图源指纹/尺寸、图题5 pt、灰框、统一底线、末页齐底、图居中、结论中插图、表头、行高和文字/单元格溢出。

整页正文使用共同底部基准。首页收稿/基金栏和图之间的局部文本框不强压到整页底线；末页做双栏平衡。正文在14.8—16 pt内调整；仍不足时使用原生文本框底部对齐并校正底部内边距，不突破行距范围。检查的是实际末行，不能仅检查框边。

检测到表格跨框时，完整入口要求核对接续处重复表头与必要的“续表”标识，未核对会阻断。复制模板续表框并自动预留位置尚未实现，不应声称已经验证。复杂公式自动送Illustrator转轮廓尚未实现；这次赵志威使用先前已验证的轮廓PDF，当前程序锁定其文件指纹/尺寸并检查链接，公式语义与形状仍需看源稿及预览。

标题语义、图表与上下文的合理断点和审美取舍仍要逐页看。所有检查通过表示本轮技术门槛通过，不替代用户终审。

## 回归

```powershell
.\tests\run_journal_roles_regression.ps1
.\tests\run_journal_layout_negative_regression.ps1 -ConfigPath "已通过配置.json" -ReportPath "回归结果.txt"
```

前一项验证导入器实际角色格式；后一项在独立临时测试副本中注入12类错误，要求被拦住，再检查原验证稿仍通过。另保留原有粗斜体、继承样式、上下标、中文斜体标点、特殊字形和上标行距回归。
